# Brief

This repository provides a generic rust library defining the base abstractions of an FTP client, and some simple implementations.

Full documentation available on the [gitlab page](https://gitlabpages.univ-lille.fr/ftp-client-91a627/ftp_client/index.html) or [github page](https://lekloono.github.io/ftp_client.rs/ftp_client/index.html) if not available from your network.
